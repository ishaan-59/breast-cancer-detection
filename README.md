# Breast Cancer Detection

Deep learning pipeline for breast cancer detection and classification from DICOM mammography images.

## Objectives

- Load and preprocess DICOM images
- Build a baseline CNN model
- Evaluate performance using medical imaging metrics
- Develop an inference pipeline

## Dataset

CBIS-DDSM

## Technologies

- Python
- PyTorch
- OpenCV
- NumPy
- pydicom
- Matplotlib
